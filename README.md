# Jogo Mario

## Descrição

Projeto de um jogo inspirado no personagem Mario, desenvolvido como atividade prática para exercitar conceitos de HTML, CSS e JavaScript.

O jogador controla o Mario e deve pular para evitar o obstáculo (cano) que se movimenta pela tela.

## Objetivo

O objetivo do projeto é praticar o desenvolvimento de uma aplicação web utilizando HTML, CSS e JavaScript, além de aplicar conceitos de organização de projetos, Git e GitHub.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
